# Самолёт · интерактивная история v0.9

[Открыть демо на GitHub Pages](https://evgenii42.github.io/sales-presenter-demo/?demo=1&edition=gemini)

Gemini 3.8 Flash — редакция по умолчанию. В панели «Сравнить текст» можно сопоставить её с исходником, Kimi и рабочей v0.8 на одном кадре. Редакции сохранены в статике.

Откройте клиентский экран из панели менеджера в том же профиле браузера. В «Репетиции» выберите «Семья и переезд · демо» и нажмите «Начать заново». История ведёт от знакомства и выбора адреса к планировке, сценарию будущей жизни и подбору. Вводные и заметки видит менеджер.

Учебные варианты в подборе используют вымышленные данные. Актуальные предложения открываются через официальные витрины.
