# Самолёт · интерактивная история v0.6

[Открыть демо на GitHub Pages](https://evgenii42.github.io/sales-presenter-demo/?demo=1)

Откройте клиентский экран из панели менеджера. Для демо оба окна должны быть в одном профиле браузера. В меню «Репетиция» доступны восемь вводных и «Семья и переезд · демо». Короткий маршрут ведёт от знакомства и хаба к школьному утру, плану, возможной продаже или аренде и подбору.

Учебные варианты в подборе используют вымышленные данные. Актуальные предложения открываются через ссылки на официальные витрины.
